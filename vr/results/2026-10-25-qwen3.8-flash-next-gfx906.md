# Qwen3.8 Flash Next on two gfx906 GPUs

Measured on two 32 GiB MI60 cards (gfx906), with TheRock ROCm 10.2.0 and the mx-llama.cpp build against upstream `344be0a60074e6395da3c4a4f300f7361df5a67d` plus the gfx906 overlay. These are single runs, not a repeated benchmark series.

## Best 100K configuration tested

| Engine / quant | Context setting | Prompt rate | Generation rate | Notes |
| --- | ---: | ---: | ---: | --- |
| mx-llama.cpp UD-IQ3_XXS | 100096 | 552.3 tok/s | 36.7 tok/s | 4,092 raw prompt tokens, 4,096 output limit, Q8_0 KV, batch/ubatch 2048 |
| Strata UD-IQ3_XXS | 9216 | 312.3 tok/s | 39.6 tok/s | 4,394 prompt tokens and 4,096 generated; IQ3_XXS pack, PLE on host |

The mx prompt was `flake.nix` duplicated back-to-back (4,092 tokens before CLI framing); `-n 4096` set the output limit. The CLI reported 552.3 prompt tok/s and 36.7 generation tok/s. The Strata run used 4,394 prompt tokens and generated 4,096. These are similar long prompts, but the engine, context setting and exact prompt framing differ, so this is not a strict same-condition comparison. On these runs, mx had the higher prompt rate; Strata had a 2.9 tok/s higher generation rate at its much smaller configured context. A shorter 2,046-token mx prompt run measured 434.7 PP / 38.0 TG and is not the long-prompt result.

During the mx 100K run, each GPU used about 31.3 GB of 34.3 GB reported VRAM, leaving about 2.8 GiB free per card. The model advertises a 262144 context limit. A one-token startup check at `-c 262144` successfully allocated the context with Q8_0 KV and batch/ubatch 2048. This confirms that the context can be configured and allocated; it does not measure a fully populated 262K conversation. Treat 262144 as the estimated maximum for this IQ3_XXS setup, with 100096 as the long-run setting measured for PP/TG.

The PLE n-gram gather table is pinned to CPU RAM by default in this build. Leave `LLAMA_PLE_SHARD` unset; setting it to `1` moves table shards into GPU memory. The 100K run used `-ngl 999 -dev ROCm0,ROCm1 -sm tensor`, assigning model layers to the two GPUs while keeping PLE on the host.

## IQ4_XS capacity attempt

The cached UD-IQ4_XS was not viable at 100K with all layers assigned to these GPUs. With Q8 KV, context allocation failed on ROCm0. Q4 KV got through KV allocation, but prefill-buffer allocation still failed after reducing batch/ubatch to 256 and rebalancing the tensor split to 45/55; the final failure requested 440 MiB on ROCm1. Do not use IQ4_XS at 100K on this machine with these settings. UD-IQ3_XXS is the highest tested cached quant that meets the 100K requirement.

Flash Next MTP2 works with the separate self-contained Q8_0 draft sidecar passed through `-md`. The matched 100K run measured 368.5 PP / 42.9 TG at batch/ubatch 1024/512; the no-MTP control at those same settings measured 396.9 / 37.3. At batch/ubatch 2048/2048, the MTP KV allocation missed VRAM by 195.5 MiB. See the [MTP diagnosis and matched comparison](2026-10-25-flash-next-mtp-short-check.md) for the command and memory limits. The separate Qwen3.8-27B Q8_0 MTP2/MTP3 results are in [the 27B CLI report](2026-10-25-qwen3.8-27b-flake-cli.md).

## Reproduction command

```sh
source /home/raistlin/amd-clean/env/therock.sh
build-ilp/bin/llama-cli \
  -m /home/raistlin/.cache/huggingface/hub/models--unsloth--Qwen3.8-Flash-Next-GGUF/snapshots/c8b5954a88c2775c546b92593eda40ea041d3176/UD-IQ3_XXS/Qwen3.8-Flash-Next-UD-IQ3_XXS-00001-of-00003.gguf \
  -f /tmp/flake-2x.nix -n 4096 -c 100096 \
  -ngl 999 -dev ROCm0,ROCm1 -sm tensor -fa on -b 2048 -ub 2048 \
  -ctk q8_0 -ctv q8_0 --temp 0 --top-k 1 --seed 42 --no-display-prompt
```

Recreate the 4K prompt with `cat flake.nix flake.nix > /tmp/flake-2x.nix`. Raw logs: `/tmp/mx-qwen38-iq3xxs-flake4kprompt-4kresponse-100k.log`, `/tmp/mx-qwen38-iq3xxs-ctx262144-check.log`, and the IQ4_XS fit attempts under `/tmp/mx-qwen38-iq4xs-*.log`. The build command `cmake --build build-ilp --target llama-cli llama-bench -j 8` passed. This was a build and workload check, not a full upstream test suite or a repeated performance sweep.
