# Historical vr archive

These files record earlier experiments and merge discussions. Their commands and performance recommendations may describe old commits or rejected configurations. Use the [active vr index](../README.md) for the current benchmark workflow and pinned port kits.

`README.md`, `RESULTS.md`, and `LOCAL_MX_IMPROVEMENTS.md` are retained as campaign records. `patches/` contains older standalone experiment diffs, not the current port kit. `build/` contains generated CMake files preserved from the old tree.
