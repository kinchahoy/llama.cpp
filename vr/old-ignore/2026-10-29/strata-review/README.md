# Strata review (2026-10-29)

Written by a review agent from reading the Strata source only (nothing built or run). The S2 row was checked against our code afterwards.

## 1. What Strata is

Strata (github.com/Niko1221/Strata) is a separate local inference engine, not a llama.cpp fork. It is mostly its own C++/CUDA engine (src/kernels/cuda/*.cu, src/prefill/*.cu) with a small pinned llama.cpp/ggml tree under third_party/, a Python server and desktop apps. It targets Qwen3.8-Flash-Next (same family as our qwen4exp), Qwen3.6 and DeepSeek V4.1, with NVIDIA as the main target. License: MIT (LICENSE, "Copyright (c) 2026 Niko1221 and the Strata contributors"). Reviewed commit 870aedd9e1ebe1c91f94da93b59af17729f6c5c0, dated 2026-10-29 (shallow clone, depth 50, so little history). Arch targets in CMakeLists.txt: NVIDIA sm_60 to sm_120 (CUDA), wave32 HIP (gfx1100, gfx1201; gfx1012/gfx1030 unvalidated; CMake line 93), Metal, SYCL, and an opt-in gfx906 build (STRATA_HIP_GFX906, CMakeLists.txt:86 and :192) that compiles the CUDA sources through a compat layer (include/strata/platform/hip_compat/). The maintainers have no gfx906 card (docs/AMD_HIP.md:549); gfx906 results are community reports (bench/results/2026-10-03-community-2x-mi50, 2026-10-04-community-mi50). Those reports use IQ1_M/IQ2_XS/IQ3_XXS with MTP speculation, expert caches and KV streaming, so their tok/s are not comparable to our Q8_0/IQ numbers. Strata has no per-kernel gfx906 before/after numbers except where quoted below.

Plain verdict: Strata has little that is new for gfx906 outside its Flash Next expert, hyper-connection and routing kernels. Its engine-level features (expert cache, KV streaming, pipeline windows, MTP windows) are a different architecture and do not map to our fork. Nothing below was built or run. All claims are from reading code and docs.

Items that support existing entries (not new):
- Strata's mode 7 puts the tokens inside the k loop so one weight load serves all window tokens (iq_kernels.cu:5919 and :5969). This is the same idea as our grouped MoE for 2-8 tokens. It supports keeping that path.
- Strata's observation that gate/up is compute-bound at about 110-130 GB/s agrees with our 150 GB/s useful expert bandwidth and with the "why Flash Next is not faster" analysis. It supports looking at ALU/lookup cost (S1, S2) before more bandwidth work.
- Strata's gr_down finding (few blocks on 60 CUs, 100 GB/s) supports priority 2 (tiny float projections) and the occupancy theme of A7.
- Strata's fused norm+quantize in the HC path (fused_gr.cu:2265, "block owns a q8_1 group") is not enabled on gfx906 (comment says HIP, not gfx906). It does not add evidence for priority 1.

## 3. Excluded: accuracy cost

- Expert skipping, expert-cache profile prefill with eviction and miss handling (docs/DISJOINT_EXPERT_CACHE.md, data/expert-profile-*.bin): changes which experts run when VRAM is short. excluded: accuracy cost (and not relevant, our experts all fit).
- INT8 and k8v4 KV (--kv int8, docs/KVA.md): lower precision KV than configured. excluded: accuracy cost.
- STRATA_GR_SPLIT, changes sum order (AMD_HIP.md:580): not bit-equal to its own default; would need a quality check on our side. Listed in S3 with that caveat.
- Speculative drafters with pruned vocab (tools/draft_vocab.py) and SPEED_PROJECTION-style knobs: output-affecting. excluded: accuracy cost.
- Multi-GPU pipeline windows (--pipeline-windows 2, +36% in a community MI50 report, AMD_HIP.md:584-597): not an accuracy trick but an engine-level pipeline stage design. Our notes say pipeline stages are cut (fork convergence decisions); not ranked.

## 4. License note

MIT (LICENSE), compatible with MIT llama.cpp. Code could be ported with the copyright notice kept. In practice the kernels are written against Strata's own data structures (NativeExpertLayout, GrMulti, grouped-expert blobs, compat layer), so only the ideas and small self-contained pieces (nib_mask sign trick, swizzle formula, wavefront top-k structure) are directly reusable. Recommend re-implementing in our ggml structures and citing Strata in the commit text if any snippet is copied. Third-party code under third_party/ keeps its own licenses.
